🚀 البدء السريع:

   npm install     # تثبيت (مرة واحدة فقط)
   npm run dev     # تشغيل الموقع
   
   👉 ثم افتح: http://localhost:3000

🎯 لتعديل أي شيء:

   1️⃣  افتح:  src/config/site.config.ts
   2️⃣  عدّل:  البيانات اللي تريدها
   3️⃣  احفظ:  Ctrl+S
   4️⃣  شاهد: الموقع يتحدث بنفسه! ✨

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 الأشياء الشائعة للتعديل:

   🔍 ابحث عن:              غيّر:
   ─────────────────────────────────────
   lawyer.name             → الاسم
   contact.numbers         → أرقام الهاتف
   contact.whatsapp        → الواتس
   colors.primary          → اللون الأزرق
   colors.secondary        → اللون الذهبي
   services                → الخدمات
   about.biography         → السيرة الذاتية
